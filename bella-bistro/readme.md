# 🍽️ Bella Bistro

Bella Bistro is a professional responsive restaurant website
designed to provide customers with information about the
restaurant, menu, gallery, and contact details.

## 📌 Project Pages

- Home
- About
- Menu
- Gallery
- Contact
- Settings

## ✨ Features

- Responsive design
- Semantic HTML5
- CSS Grid
- Flexbox
- SCSS/SASS
- JavaScript interactions
- Contact form validation
- Responsive mobile design
- Restaurant image gallery
- Accessibility-friendly images
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- SCSS/SASS
